# A/B Testing Service

Веб-сервис для продуктовых аналитиков и маркетологов, который помогает правильно планировать и оценивать A/B-тесты.

Сервис позволяет:
- рассчитать необходимый размер выборки перед запуском эксперимента;
- провести статистическую оценку результатов (p-value, uplift, доверительные интервалы);
- сохранять эксперименты и историю расчётов.

**Ссылка на рабочий проект:** будет добавлена после деплоя на PythonAnywhere

## Технологии

- **Python** 3.12
- **Django** 5.x
- **SciPy**, **Statsmodels**, **NumPy**, **Pandas** — статистические расчёты и обработка данных
- **Bootstrap 5** — интерфейс (в разработке)

## Основные возможности

- Калькулятор размера выборки
- Статистическая оценка результатов A/B-теста
- Хранение экспериментов пользователя
- Административная панель Django

## Как запустить проект локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/futurefroggoose/ab-testing-service.git
   cd ab-testing-service
   ```
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate   # Mac / Linux
   venv\Scripts\activate      # Windows
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Примените миграции:
   ```bash
   python manage.py migrate
   ```
5. Создайте суперпользователя:
   ```bash
   python manage.py createsuperuser
   ```
6. Запустите сервер:
   ```bash
   python manage.py runserver
   ```
7. Откройте в браузере: http://127.0.0.1:8000/admin
