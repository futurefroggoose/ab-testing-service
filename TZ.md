# Техническое задание на проект

**Название проекта:**  
Веб-сервис для продуктовых аналитиков и маркетологов с целью автоматизации A/B-тестирования: расчет размера выборки и статистическая оценка результатов

## 1. Цель проекта

Создание веб-сервиса, который помогает продуктовым аналитикам и маркетологам корректно планировать и оценивать A/B-тесты.  
Сервис позволяет:
- Рассчитать необходимый размер выборки до запуска эксперимента
- Провести статистическую оценку результатов после завершения теста (p-value, доверительные интервалы, относительный uplift)

Цель сервиса — снизить количество некорректно проведённых экспериментов и ускорить принятие решений на основе данных.

## 2. Роли пользователей

- **Гость** — может пользоваться калькулятором размера выборки и оценкой результатов без регистрации (результаты не сохраняются).
- **Зарегистрированный пользователь** — может сохранять эксперименты, историю расчётов, создавать несколько вариантов и возвращаться к ним позже.
- **Администратор** — полный доступ через Django Admin.

## 3. Модели данных (сущности)

### Experiment (Эксперимент)
- name — название эксперимента
- description — описание
- baseline_conversion — базовая конверсия (%)
- mde — минимально обнаруживаемый эффект
- alpha — уровень значимости
- power — статистическая мощность
- status — статус (draft / planned / completed)
- created_by — кто создал (связь с User)
- created_at, updated_at

### Variant (Вариант)
- experiment — связь с экспериментом (ForeignKey)
- name — название варианта (A, B, Control и т.д.)
- visitors — количество посетителей
- conversions — количество конверсий
- is_control — является ли контрольным вариантом

### StatisticalResult (Статистический результат)
- experiment — связь с экспериментом (OneToOne)
- sample_size_per_variant — рассчитанный размер выборки
- p_value — p-value
- relative_uplift — относительный прирост (%)
- confidence_interval_lower / upper — доверительный интервал
- is_significant — статистически значимый результат
- calculated_at — дата расчёта

## 4. Ключевой функционал (User Stories)

1. Как гость/пользователь, я могу ввести параметры эксперимента (базовая конверсия, MDE, alpha, power) и получить расчёт необходимого размера выборки на каждый вариант.
2. Как пользователь, я могу создать эксперимент, добавить в него несколько вариантов и сохранить его.
3. Как пользователь, я могу ввести фактические данные по вариантам (visitors + conversions) и получить статистическую оценку: p-value, uplift, доверительный интервал и вывод о значимости.
4. Как пользователь, я могу просматривать историю своих экспериментов и результаты расчётов.
5. Как пользователь, я могу видеть наглядную визуализацию результатов.

## 5. Внешние интеграции / Аналитика

- Основная аналитика: библиотеки `scipy`, `statsmodels`, `numpy`, `pandas` для расчёта размера выборки и статистических тестов.
- Визуализация: `matplotlib` / `plotly` или Chart.js.
- (Опционально) загрузка данных из CSV.
